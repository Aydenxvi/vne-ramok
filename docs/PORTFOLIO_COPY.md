# VNE RAMOK — Portfolio copy

Use the descriptions below when creating a personal portfolio website, CV, or project listing.

## English — project card (short)

**VNE RAMOK — Interactive Fashion Storefront**  
Full-stack portfolio project featuring an editorial streetwear catalog, clickable lookbook, lightweight 3D outfit builder, demo checkout and animated receipt. Built with vanilla JavaScript, WebGL, Node.js and SQLite, and deployed on Render.

**Role / scope:** Concept, UI/UX, frontend interactions, 3D integration, backend and deployment.  
**Links:** [Live demo](https://vne-ramok-portfolio.onrender.com/) · [Source](https://github.com/Aydenxvi/vne-ramok)

## Русский — карточка проекта

**VNE RAMOK — интерактивный магазин одежды**  
Full-stack проект для портфолио: каталог стритвир-одежды, интерактивный LOOKBOOK, 3D-конструктор образов, демонстрационное оформление заказа и анимированный чек. Технологии: HTML/CSS, JavaScript, WebGL, Node.js и SQLite. Публичная демоверсия размещена на Render.

**Важно:** демонстрационный проект, без реальных платежей и сохранения персональных данных посетителей.
