# VNE RAMOK — план видеодемонстрации (50–60 секунд)

- **0–8 сек:** крупный заголовок на главной; медленный скролл, лёгкий hover по основной кнопке.
- **8–16 сек:** New Drop — переключить 2–3 товара.
- **16–26 сек:** LOOKBOOK — нажать на hotspot и показать товар.
- **26–42 сек:** OUTFIT STUDIO — повернуть манекен на 30–45°, сменить верх, низ и цвет. Показывать модель целиком.
- **42–48 сек:** добавить образ в корзину и открыть оформление.
- **48–57 сек:** оформить фиктивный заказ и захватить **движение печати чека**, не только финальный кадр.
- **57–60 сек:** финальный экран/логотип + Live demo URL.

## Настройки записи

- Формат: 1920×1080 (16:9), 30 FPS, MP4, H.264; можно без озвучки.
- Запись: OBS Studio или Xbox Game Bar (`Win + Alt + R`).
- Перед началом закрой лишние вкладки, уведомления и терминалы; включи полноэкранный браузер, если это улучшает композицию.
- Используй только демо-данные при оформлении, не показывай реальные адреса или аккаунты.
- Сделай 1 длинный исходный ролик, затем смонтируй короткую версию. Если сервер Render просыпается медленно, открой сайт заранее.
