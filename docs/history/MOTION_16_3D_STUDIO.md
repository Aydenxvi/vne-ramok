# VNE RAMOK — MOTION 16 / OUTFIT STUDIO 3D

## Что изменилось

Вместо плоского SVG-манекена конструктор показывает **настоящую вращаемую 3D-сцену** (WebGL), которая строит объёмный стилизованный манекен процедурно: объёмные футболки, худи с капюшоном, куртки с молнией, широкие джинсы и карго с карманами, кеды, дополнительную шапку. Выбор цвета в конструкторе сразу применяется к объёмной одежде.

**Управление:** перетаскивание мышью или пальцем — вращение, кнопки `↶`, `FRONT`, `↷` — предустановленные повороты, `+` — увеличение, на клавиатуре стрелки при фокусе на модели.

### Про производительность

- WebGL загружается только когда пользователь приближается к секции OUTFIT STUDIO.
- Нет непрерывного `requestAnimationFrame` — кадры перерисовываются только при взаимодействии, изменениях или изменении размеров окна.
- Плотность пикселей ограничена `1.6x`, используются лёгкие геометрии и простое освещение.
- При отсутствии WebGL конструктор автоматически остаётся на прежнем работающем SVG-эскизе.
- Весь 3D-движок — самостоятельный `outfit-3d.js`, без CDN, npm, загрузок 3D-моделей и внешних библиотек.

### Что остаётся демо

Это **стилизованная 3D-визуализация**, а не физическая примерка: геометрия не совпадает в точности с фотографиями SKU, не отражает реальную посадку/размер и не имитирует поведение ткани. Следующий уровень реализма потребует уникальных 3D-моделей одежды (GLB/glTF), сканов тканей/материалов и отдельного 3D-пайплайна. Не выдавайте текущую функцию за AR-примерку.

## Запуск

На Windows — `start_windows.bat`, затем `http://localhost:3000`, прокрутите к **OUTFIT STUDIO**. Старые разделы, анимация чека, корзина, админка и локальная SQLite не изменены.

**Обновление установленного MOTION 15:** остановить сервер `Ctrl+C`, сделать резервную копию, скопировать файлы из ZIP-патча в корень `vne-ramok` с заменой, запустить `start_windows.bat`, обновить страницу `Ctrl+F5`. Папку `data` **не заменять**.

## Проверки

- JS синтаксис: `node --check outfit-3d.js`, `node --check wardrobe.js`.
- `npm test`: тесты каталога/корзины/конструктора/чека, геометрического 3D-движка, поворота клавиатурой, резерва SVG и 9 серверных интеграционных сценариев.
- Живую WebGL-картинку на реальном GPU и стабильность FPS следует проверить на компьютере пользователя, так как автоматический Chromium в среде сборки блокирует открытие страниц. Результаты тестов не доказывают идеальное визуальное отображение на всех видеокартах.
