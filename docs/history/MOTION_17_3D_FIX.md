# VNE RAMOK 17 — видимость 3D и диагностика

## Изменения
- В области OUTFIT STUDIO всегда видна метка **VNE 17 / 3D**. Если метки нет, пользователь открыл старую версию/старую папку/кэшированную страницу.
- После первого 3D-кадра появляется **3D АКТИВНО / 360°** и кнопки поворота.
- Если WebGL блокируется, показывается **WEBGL НЕДОСТУПЕН**, подсказка и кнопка повтора вместо молчаливого показа SVG.
- Подключения 3D-файлов получают version=17, поэтому браузер не должен использовать старые JS/CSS из кэша.
- 3D-движок по-прежнему рисует кадры только по необходимости. Каталог, заказы, база данных и чек не изменены.

## Windows
1. Закрой прежний сервер через Ctrl+C.
2. Создай резервную копию папки и файлов базы данных.
3. Распакуй ZIP с полной версией в отдельную папку ИЛИ скопируй содержимое PATCH в старую папку `vne-ramok` с заменой (файлы из корня PATCH должны лежать рядом с index.html).
4. Запусти **именно новый** start_windows.bat.
5. Открой http://localhost:3000, нажми Ctrl+Shift+R и прокрути до «СОБРАТЬ ОБРАЗ».
6. Проверь метку **VNE 17 / 3D**. Затем **3D АКТИВНО / 360°** — 3D работает.
7. Если видишь **WEBGL НЕДОСТУПЕН**, проверь в Edge/Chrome Настройки → Система → Использовать аппаратное ускорение, если доступно, перезапусти браузер и нажми «ЗАПУСТИТЬ 3D».

## Ограничения
Это стилизованная WebGL-модель, не физическая примерка. На браузерах без WebGL останется SVG и будет видимое сообщение об этом.
